## 🌐 What is GitHub?

**GitHub** is an online platform used to store, share, and manage programming code and projects.

Think of it like **Google Drive for programming projects**.

- 📁 **Repository** = Project folder
- 📄 **File** = Program/code
- 🌐 **GitHub** = Online platform where the project is stored

You **do not need to know programming or Git commands** to access the programs in this repository.

# 📱 How to Access Using Mobile

### Method 1 – Using Chrome/Safari

1. Open **Chrome** on Android or **Safari/Chrome** on iPhone.
2. Open the repository link:

   https://github.com/vegapunk-hub/FD-Lab-Programs

3. You will see folders such as:

   - `Program-1`
   - `Program-2`
   - `Program-3`
   - `Program-4`

4. Tap any folder to open it.
5. Tap the required file, such as `index.html`.
6. You can now **view the program code**.

### 📥 Download All Programs on Mobile

1. Open the repository.
2. Tap the **Code** button.
3. Select **Download ZIP**.
4. The complete repository will be downloaded as a ZIP file.
5. Extract the ZIP file to access all programs.

> 💡 You don't need the GitHub app just to view or download these programs. Your mobile browser is enough.

# 📥 How to Download the Programs on Desktop

To download **all programs at once**:

1. Open the repository.
2. Click **Code**.
3. Click **Download ZIP**.
4. Open your Downloads folder.
5. Extract the ZIP file.
6. Open the extracted folder.
7. You will find all the lab programs inside.

---

# 👀 How to View a Program

For an HTML program:

1. Open the program folder.
2. Click `index.html`.
3. GitHub will display the source code.
4. Click the **Raw** button if you want to see the plain source code.

⚠️ **Important:** GitHub normally displays HTML as code. It does not automatically run the webpage like a normal browser.

To actually run the HTML program, download the files and open `index.html` on your computer using a web browser or a code editor such as VS Code.

---

# 📂 Understanding the Program Structure

A program may contain more than one file.

Example:

```text
Program-3
│
├── index.html
└── style.css
```

Here:

**`index.html`** → Structure/content of the webpage

**`style.css`** → Design and styling of the webpage

Keep both files in the **same folder** unless instructed otherwise.
