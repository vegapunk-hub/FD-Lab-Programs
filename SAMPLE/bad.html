What Is Going Wrong Here?

The words are identical to the good version. Only the CSS changed. Use “Switch Design” to compare.

  1. Too many fonts. Five unrelated typefaces make the page look like a ransom note.
  2. Clashing colors. Red, neon green, yellow and purple compete for attention.
  3. Random text sizes. An 88px headline sits next to a 10px paragraph, so there is no hierarchy.
  4. Uneven spacing and alignment. Every section starts at a different position.
  5. Inconsistent buttons. Each button has a different shape, size, color and font.
  6. Poor contrast. Pale text on bright backgrounds is tiring and hard to read.
  7. Awkward wrapping and random capitals. The eye never knows where to go next.
